Galileu Aberto

Dados agregados do uso do Galileu na Justiça do Trabalho, abertos para pessoas e agentes de IA, e um chat open source para testar os mesmos modelos. Projeto independente, sem vínculo oficial com o TRT4.

Modelos

Antes de usar. Esta é uma implementação independente: não usa os prompts do Galileu real e não substitui o trabalho de magistrados. Não cole dados reais de processos, nomes ou documentos sigilosos. A conversa vai direto do seu navegador ao Google; sua chave de API fica só neste navegador (sessão) e nunca passa por nós.

Baixar dados

Todos agregados, sem nomes, usuários ou números de processo. CSV e JSON abaixo; Parquet no repositório.

    Para agentes de IA

    Descoberta em llms.txt e esquema em datapackage.json. Sem servidor: leia os JSON estáticos.

    curl -s https://developerfred.github.io/galileu-aberto/data/minutas_diarias.json

    Servidor MCP local (stdio) no repositório: mcp/server.py.

    Como ler estes números

    • Minutas são processos distintos com minuta gerada. Não somam entre dias, meses ou graus: um processo pode aparecer em mais de um período. Só o total oficial, 458.696, é distinto no conjunto todo.
    • Requisições são registros de uso dos modelos (uma minuta pode gerar várias); essas somam normalmente.
    • Tokens medem o volume de texto enviado (entrada) e gerado (saída).
    • Os dados vêm do painel público do Galileu, coletado em . Podem mudar quando o painel for atualizado.
    • Nada aqui identifica magistrados, servidores ou processos.
